# PowerChain Public Visual Assets

Organized reference and production-ready visual assets for PowerChain ACP, commerce, renewables, IoT and DePIN product surfaces.

## Folders

- `images/architecture/` — system maps, ACP flows, DePIN/energy architecture.
- `illustrations/` — renewable energy, smart-grid, DePIN, agent commerce and marketplace illustrations.
- `images/` — full product references, desktop/mobile dashboards, storefront and checkout references.
- `icons/` — reusable icon strip and individual reference icons.

## Naming
Use lowercase kebab-case. Keep UI screenshots in `images/`, diagrams in `images/architecture/`, decorative/domain scenes in `illustrations/`, and small reusable symbols in `icons/`.
